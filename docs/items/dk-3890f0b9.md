# Pin GitHub Actions to commit SHAs in ci.yml


The CI workflow (`.github/workflows/ci.yml`) references `actions/checkout@v4`, `actions/setup-node@v4` and `cloudflare/wrangler-action@v3` by floating major tag. `wrangler-action` receives `CLOUDFLARE_API_TOKEN`, so a compromised tag could exfiltrate it.

**Why:** supply-chain hardening; raised as P2 by the 2026-10-15 structure review of the CI-gated deploy. Judged acceptable for a personal site for now.

**Direction:** pin each action to a full commit SHA (with a `# vX.Y.Z` comment), optionally with Dependabot for `github-actions` to keep the pins current.
