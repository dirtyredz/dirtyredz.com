# Upgrade react-router to v7 to clear two Dependabot alerts

Filed 2026-10-13 from Dependabot triage. Resolved 2026-10-13 in commit 5594033.

Two open runtime alerts sat on transitive `react-router` (>= 6.0.0 < 7.18.0), patched only in 7.18.0, a major upgrade from the v6 the site used:

- #291 (medium): open redirect via a backslash in `<Link>` / `useNavigate` (a bypass of CVE-2025-68470). Real exposure was low: the site's links and navigations are hardcoded.
- #290 (medium): arbitrary constructor injection via `deserializeErrors()` during SSR hydration. Not applicable: client-only Vite SPA, no SSR.

**Resolution.** `react-router-dom` ^6.26.2 was replaced by `react-router` ^7.18.0 (7.18.4 installed), staying in declarative/library mode (BrowserRouter / Routes / Link / NavLink). The only code change was the import path, from `react-router-dom` to `react-router`, in `src/App.jsx`, `src/main.jsx`, `src/components/Nav.jsx`, `src/components/Footer.jsx`, `src/pages/Home.jsx` and `src/pages/NotFound.jsx`. The v6 future-flags step was skipped because nothing else changed. `public/_redirects` and `vite.config.js` needed nothing. STRUCTURE.md now names React Router 7 and Vite 6.

**Verified.** `npm audit` reported 0 vulnerabilities. `npm run build` passed, and `npm run dev` booted. A browser smoke check on the built preview passed for every route: Home, Mods, Projects and About, each via nav clicks and direct loads, plus the /nope 404, back/forward, and the NavLink active state. Production-preview console capture was incomplete.
