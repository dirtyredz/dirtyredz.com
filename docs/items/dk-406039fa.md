# Upgrade react-router to v7 to clear two Dependabot alerts


Filed 2026-10-13 from Dependabot triage. Two open runtime alerts on transitive `react-router` (>= 6.0.0 < 7.18.0), patched only in 7.18.0, which is a major upgrade from the v6 the site uses:

- #291 (medium): open redirect via a backslash in `<Link>` / `useNavigate` (a bypass of CVE-2025-68470). Real exposure is low: the site's links and navigations are hardcoded, not built from user input.
- #290 (medium): arbitrary constructor injection via `deserializeErrors()` during SSR hydration. **Not applicable**: this is a client-only Vite SPA with no SSR.

**Direction.** Upgrade `react-router-dom` v6 → v7 (in v7 the package is `react-router`), following the official v6→v7 migration guide (future flags first). The routes in `src/App.jsx` are simple, so this should be small. Fast gate: `npm run build`, plus clicking through every route in `npm run dev`.
