# Upgrade react-router to v7 to clear two Dependabot alerts

Reported 2026-10-11 by the dk-5f296e71 agent: `node --test test/server/server-session.test.js` has 12/13 passing on master; "Stop during streaming ends the turn before tools or questions" fails identically on master and on its branch.

Cause (found 2026-10-11): a timing race in the test, not a code regression and not D10 or the auto-resume merge. The fake's default turn streams three text deltas 100 ms apart, then launches the Agent and Bash tool. The test posted /api/stop after seeing the first text; on a loaded machine the stop request took longer than the ~300 ms window, so the tool card existed before the interrupt landed. It passed 13/13 on an idle box and failed 10 of 10 with ten parallel runs. Fix: the fake gains `streamHold` (parks the turn after the first text delta until interrupted) and the test uses it.
