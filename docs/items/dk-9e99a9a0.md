# Split fetchRepos into a pure fetchLiveItems() and a cached wrapper


Raised by the push review on 2026-10-13 (componentization + abstraction lenses, both P2).

`fetchRepos({useCache})` in `src/lib/github.js` now mixes cache policy, transport plus the 8 s timeout, classification and sorting. The `useCache:false` flag exists only so `scripts/generate-fallback.mjs` can run it in Node. It works because `readCache`'s try/catch swallows the missing `sessionStorage`.

**Direction.** Extract a pure `fetchLiveItems()` (fetch, timeout, classify, sort) and keep a thin cached `fetchRepos()` wrapper for the browser. The generator calls `fetchLiveItems()` and the flag goes away. Do it together with the cache change (dk-517a7ebf), or when github.js next grows.
